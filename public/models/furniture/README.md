# KayKit — Furniture Bits

The local glTF models are from Kay Lousberg's free Furniture Bits 1.0 pack.
The pack is CC0 1.0 Universal; the original license is included as `LICENSE.txt`.

- Creator page: https://kaylousberg.com/game-assets/furniture-bits
- Official asset pack: https://kaylousberg.itch.io/furniture-bits
- Creator's GLTF repository: https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0
- License: https://creativecommons.org/publicdomain/zero/1.0/

Selected GLTF models and their `.bin` buffers are stored beside the shared
`furniturebits_texture.png` atlas in `kaykit/`. The wardrobe remains a custom
low-poly mesh because the free pack has no closet model. Imported objects are
scaled uniformly to preserve their proportions; catalog dimensions still drive
placement, selection, and clearance behavior.
